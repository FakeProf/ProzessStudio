Schnellstart

Element anklicken → im Kontextmenü daneben z. B. Aufgabe anhängen: das neue Element ist sofort verbunden.

Mit Auto-Verbinden wird auch alles aus der linken Palette automatisch an das ausgewählte Element angehängt.

Mehrere Elemente mit Shift+Klick wählen, dann V: werden von links nach rechts verbunden.

N oder + Alle Elemente = Schnellmenü mit allen Typen (Zeit-, Nachrichten-, Randereignisse …) inkl. Suche.

Doppelklick = beschriften. R auf Element = Typ ändern.

Geschäftsregeln: + Regel legt eine Entscheidungstabelle (DMN) an. Eine Geschäftsregelaufgabe im Prozess lässt sich rechts unter Eigenschaften damit verknüpfen.

Geschäftsregeln (DMN)

Neue RegelLegt eine Entscheidungstabelle an. Spalten Wenn = Eingaben (Bedingungen), Dann = Ausgaben (Ergebnis). Jede Zeile ist eine Regel.
SpaltenkopfAnklicken, um Bezeichnung, Ausdruck (Variablenname) und Typ zu bearbeiten. Rechtsklick in die Tabelle = Zeilen/Spalten einfügen, kopieren, löschen.
ZellenTexte in Anführungszeichen ("Gold"), Zahlen mit Vergleich (>= 1000, [100..500]), - oder leer = egal.
Hit PolicyLinks oben in der Tabelle: legt fest, was gilt, wenn mehrere Regeln zutreffen (U = genau eine, F = erste, C = alle sammeln …).
Übersicht (DRD)Entscheidungsanforderungsdiagramm: mehrere Entscheidungen, Eingabedaten und Wissensquellen und ihre Abhängigkeiten. Tabellen-Symbol an einer Entscheidung öffnet deren Tabelle.
VerknüpfenIm Prozess eine Geschäftsregelaufgabe wählen → rechts Entscheidung auswählen oder + Neue Entscheidungstabelle. Gespeichert als camunda:decisionRef (Camunda-kompatibel).
PrüfenFindet leere Regeln, fehlende Ergebnisse, doppelte Regeln bei Hit Policy U und Texte ohne Anführungszeichen.
